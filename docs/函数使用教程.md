# 函数使用教程

本文讲清楚工程里**每个能调用的函数怎么用**：参数什么单位、返回值什么意思、能传什么值、
用错了会怎样，最后给几个能直接抄的实战例子。

> 配套代码：`Core/Inc/leg_ik.h`、`Core/Src/leg_ik.c`、`Core/Inc/gait.h`、`Core/Src/gait.c`、
> `Core/Inc/pca9685.h`、`Core/Src/pca9685.c`。
>
> 关节命名全工程统一为 **髋 / 股 / 膝**：
> **髋关节** = 水平面旋转；**股关节** = 股连杆的抬落；**膝关节** = 胫连杆相对股连杆的夹角。

---

## 0. 先看全局：三层结构

```text
  你写的动作               几何层                角度层                  驱动层
  ┌──────────┐   ┌────────────────────┐   ┌────────────────────┐   ┌──────────────────────┐
  │ 足端坐标  │ → │ inverseKinematics  │ → │ hip/femur/tibia_   │ → │ PCA9685_Set_Servo_   │ → PWM
  │ (x,y,z)mm│   │  → LegAngles(弧度) │   │ angle → 0~180°     │   │ Angle(ch 0~17, 0~180)│
  └──────────┘   └────────────────────┘   └────────────────────┘   └──────────────────────┘
      gait.c           leg_ik.c                 gait.c                    pca9685.c
```

| 层 | 文件 | 函数 | 输入单位 | 输出单位 |
|---|---|---|---|---|
| 几何层 | `Core/Src/leg_ik.c` | `inverseKinematics()` | mm | 弧度 |
| 角度层 | `Core/Src/gait.c` | `hip_angle()` / `femur_angle()` / `tibia_angle()`（内部 static） | 弧度 | 0~180 度 |
| 驱动层 | `Core/Src/pca9685.c` | `PCA9685_Set_Servo_Angle()` | 度 | PWM tick |
| 高层 | `Core/Src/gait.c` | `Gait_Init()` / `Gait_TripodStep()` / `Gait_WalkSteps()` | mm | — |

**关键点**：几何层只管"数学角"，绝不掺舵机安装方向；所有"机械中位 ↔ 舵机 90°"的换算
**只**在角度层做。这样换舵机/换装法时只改一张表，不动数学。

### 0.1 几何模型（现场实测口径）

所有舵机 90° 时**整条腿竖直向上**，股连杆 + 胫连杆构成**竖直面内的两自由度平面臂**：

```text
              中性姿态轴（舵机 90°/90° 时整条腿的指向，竖直向上）
                    ↑
                    │  ∠1 = 股关节角，相对中性姿态轴，±90°
                    │
                 ┌──┴──┐  股连杆 L2 = 57.9 mm
                 │     │
                 └──┬──┘
                    │  ∠2 = 膝关节角，相对股连杆延长线，±90°
                    │
                    ▼  胫连杆 L3 = 110.0 mm
                    ●  足端
```

- 两个关节的机械行程都是 **±90°**；
- 舵机值 = `90 + ∠`；
- 因为 `∠2 ∈ [−90°, +90°]`，`cos∠2 ≥ 0`，所以髋到足端的直线距离
  **d 一定在 `124.3 ~ 167.9 mm`** 之间（伸不到更近，这是这套几何的硬约束）。

> 如果换了装配方向（舵机 90° 时腿其实朝下），只改 `Core/Inc/leg_ik.h` 里的
> `LEG_IK_NEUTRAL_UP`：`1` = 朝上（当前）、`0` = 朝下。角度层一行都不用动。

## 1. 全局约定（看错这里 = 90% 的 bug）

### 1.1 坐标系

相对**该腿的髋关节旋转中心**：

| 轴 | 正方向 | 例子 |
|---|---|---|
| `x` | 向前 | 足端比髋靠前 50 mm → `x = +50` |
| `y` | 向左 | 左腿足端在外侧 → `y = +117`；右腿 → `y = -117` |
| `z` | 向上 | 足端在身体下方 → `z = -75` |

单位 **mm**。一次调用只算**一条腿**，六条腿各调一次。

### 1.2 腿号与通道号

| 腿号 | 位置 | 髋/股/膝 逻辑通道 |
|---|---|---|
| 1 | 前左 | 0 / 1 / 2 |
| 2 | 中左 | 3 / 4 / 5 |
| 3 | 后左 | 6 / 7 / 8 |
| 4 | 前右 | 9 / 10 / 11 |
| 5 | 中右 | 12 / 13 / 14 |
| 6 | 后右 | 15 / 16 / 17 |

通道 0~8 在板 1（0x40），9~17 在板 2（0x60）。**C 数组下标是 0~5，对应腿 1~6。**

### 1.3 角度约定

- 舵机角度统一 **0~180°**，90° = 机械中位（现装法下 = 该关节与中性姿态轴对齐）
- 软限位：**髋 15~165°**，**股 / 膝 5~175°**（股/膝要放宽，因为正常站姿就落在 160 附近）
- IK 输出的 `femur` 是 **∠1**、`tibia` 是 **∠2**，都是"相对量"，不是绝对倾角：
  `0` = 与参考轴/股连杆共线（舵机 90°），`+π/2` = 摆到垂直

## 2. 几何层：`inverseKinematics()`

```c
LegAngles inverseKinematics(float x, float y, float z);
```

### 2.1 参数

| 参数 | 类型 | 单位 | 说明 |
|---|---|---|---|
| `x` | float | mm | 足端相对髋中心的前后位置，正=前 |
| `y` | float | mm | 左右位置，左腿为正、右腿为负 |
| `z` | float | mm | 上下位置，足端在下 → 负值 |

### 2.2 返回值 `LegAngles`

| 字段 | 单位 | 含义 |
|---|---|---|
| `.hip` | 弧度 | 髋关节方位角。`0` = 腿朝正前，`+π/2` = 朝正左 |
| `.femur` | 弧度 | 股关节 **∠1**，相对中性姿态轴；`0` = 与轴重合（舵机 90°） |
| `.tibia` | 弧度 | 膝关节 **∠2**，相对股连杆延长线；`0` = 与股连杆共线（舵机 90°） |

### 2.3 例子：中左腿回到 home

```c
LegAngles a = inverseKinematics(0.0f, 117.2f, -75.2f);
/* 结果（角度换算后）：
 *   hip   =  90.0°   （朝正左）
 *   ∠1    =  74.0°   （股连杆接近水平）
 *   ∠2    =  72.0°   （胫连杆相对股连杆折 72°，足端落到髋下方 75 mm）
 * 对应舵机（见下节，股关节 DIR_FEMUR = −1）：髋 90.0 / 股 16.0 / 膝 162.0
 */
#define RAD2DEG(r)  ((r) * 57.29578f)
```

### 2.4 越界会怎样（重要）

腿的工作空间（髋关节旋转中心 → 足端 的直线距离 d）：

```text
最近 d = hypot(L2, L3) = 124.3 mm   （∠2 被 ±90° 限死，腿伸不到更近）
最远 d =  L2 + L3      = 167.9 mm   （腿完全伸直）
```

超出范围时**不会**像旧代码那样返回全 0（那会让整条腿瞬间甩到 0°），分两级保护：

1. **目标点沿"髋→足端"视线缩放到最近的可达边界**（`leg_ik.c` 的工作空间保护段）；
2. **关节角再夹到 ±90°**，保证不会顶过机构死点。

所以输出的角度连续、不会跳变；足端实际到不了你给的点，但方向是对的。
想确认有没有被截断，用 `python tools/ik_check.py` 算，或看 `d` 是否 < 124.3 / > 167.9。

### 2.5 三个常见错误

| 写法 | 后果 | 正确做法 |
|---|---|---|
| `inverseKinematics(0, 0, -75)` | 足端压在髋轴上，`d < 1mm` 走病态保护，方向未定义 | `y` 必须给腿的横向偏移 |
| `inverseKinematics(50, 60, 0)` | z≈0 = 足端与髋同高，`d≈78 < 124.3`，腿被投影到极限伸直 | 站姿 `z` 取 −70~−80 |
| 传 `(50, 60, -75)` 的毫米值当米 | 角度会瞬间打满限幅 | 只认 mm |

## 3. 角度层：`hip_angle()` / `femur_angle()` / `tibia_angle()`

这三个是 `gait.c` 里的 **static 内部函数**，签名：

```c
static uint8_t hip_angle  (int leg, float rad);   /* leg = 0~5，对应腿 1~6 */
static uint8_t femur_angle(int leg, float rad);
static uint8_t tibia_angle(int leg, float rad);
```

它们干的事（`gait.c` 的 `joint_angle()`）：

```text
servo = 90 + DIR[leg] × (ikDeg - MID[leg]) + TRIM[ch]
然后髋限幅 15~165、股/膝限幅 5~175，四舍五入成 uint8_t
```

| 关节 | `MID`（舵机 90° 时该关节的 IK 角） | `DIR` | 依据 |
|---|---|---|---|
| 髋 | 左腿 `+90°`、右腿 `-90°` | 左 `+1`、右 `-1` | 舵机 90° 时腿指向该腿正外侧 |
| 股 | `0°`（与中性姿态轴重合） | 全 `-1`（实测装法该关节方向相反） | 现装法：90°/90° 时整条腿竖直向上，伺服正向对应 ∠1 减小 |
| 膝 | `0°`（与股连杆共线） | 全 `+1` | 同上 |

> 所以股关节的换算实际是 `servo = 90 − ∠1`：home 的 ∠1 = 74° → 股 servo 16.0°。
> 别被"数字小"误导，16° 是这条腿正常站姿的位置；股关节装反过的话把 `DIR_FEMUR` 全改回 `+1` 即可。

为什么不能像旧代码那样"三个关节一律 +90°"：现装法下 90° 对应的是"腿竖直向上"，
站立姿态在 160 附近；旧映射会把髋/膝硬顶到 0°/180°。详见《代码修改指导手册》M2/M4。

### 3.1 想改哪里就改哪里

| 现象 | 改这个（`Core/Src/gait.c`） |
|---|---|
| 某条腿某个关节**转反**了 | `DIR_HIP[6]` / `DIR_FEMUR[6]` / `DIR_TIBIA[6]` 对应格改成 `-1` |
| 某一路**固定偏几度** | `SERVO_TRIM[18]`，下标 = 腿号(0~5)×3 + 关节(0髋/1股/2膝) |
| 六条腿髋**整体**偏同一角度 | `HIP_MID_DEG[6]` |
| 想收紧软限位 | `HIP_MIN_DEG` / `HIP_MAX_DEG`、`LEG_MIN_DEG` / `LEG_MAX_DEG` |
| 舵机 90° 其实是腿朝下 | `Core/Inc/leg_ik.h` 的 `LEG_IK_NEUTRAL_UP` 改成 `0` |

例：1 号腿髋偏 -4° → `SERVO_TRIM[0] = -4`；4 号腿膝转反 → `DIR_TIBIA[3] = -1`。

### 3.2 单腿控制（已经在 `gait.c` / `gait.h` 里内置）

`main.c` 直接调这三个函数就能单独摆一条腿，**不需要再自己加包装**：

```c
void Gait_SetFoot(uint8_t leg, float x, float y, float z);
void Gait_SetJointAngles(uint8_t leg, float hip_deg, float femur_deg, float tibia_deg);
void Gait_Home(void);
```

**腿号统一 1~6**（和 `LEG_HOME` 顺序一致）：1 前左、2 中左、3 后左、4 前右、5 中右、6 后右。
腿号越界（<1 或 >6）函数直接返回，不会写舵机。

| 函数 | 参数含义 | 什么时候用 |
|---|---|---|
| `Gait_SetFoot(leg, x, y, z)` | 足端坐标 mm，相对该腿**髋关节旋转中心**；x 前 / y 左 / z 上（脚在下方时 z 负） | 想让某条腿去某个位置——**最常用**，内部自动 IK + 角度换算 + 越界保护 |
| `Gait_SetJointAngles(leg, hip, femur, tibia)` | 三个**关节角（度）**：`hip` 方位角（0=正前，+90=正左）、`femur` ∠1（±90）、`tibia` ∠2（±90） | 标定单个舵机、怀疑 IK 有问题时手动摆角度——**跳过 IK**，不做可达性检查 |
| `Gait_Home()` | 无参数 | 六条腿一起回 home（等价于 `Gait_Init()`，但可运行中随时调用） |

```c
/* 1) 把 2 号腿摆到 home（中左腿） */
Gait_SetFoot(2, 0.0f, 117.2f, -75.2f);

/* 2) 1 号腿抬起来 30 mm：z 从 -75.2 变成 -45.2，x/y 不变 */
Gait_SetFoot(1, 75.3f, 89.7f, -45.2f);

/* 3) 只测某个舵机：直接给角度（1 号腿 home 的 IK 角 = 髋 50 / ∠1 74 / ∠2 72，
 *    经角度层后舵机 = 髋 50 / 股 16 / 膝 162） */
Gait_SetJointAngles(1, 50.0f, 74.0f, 72.0f);

/* 4) 调完回中位 */
Gait_Home();
```

单腿摆位会立刻写 3 路舵机，**没有延时、不阻塞**；舵机按自己的速度转过去。
要注意：`Gait_SetFoot` 只动这一条腿，另外五条腿保持原状——想让它不摔，先 `Gait_Home()` 再动一条腿。

## 4. 驱动层：`pca9685.c`

```c
void PCA9685_Init(I2C_HandleTypeDef *hi2c1, I2C_HandleTypeDef *hi2c2);
void PCA9685_Set_Servo_Angle(uint8_t channel, uint8_t angle);
```

### 4.1 `PCA9685_Init()`

- 传两条 I2C 总线（板 1 用 `hi2c1`，板 2 用 `hi2c2`，**地址不同**）
- 内部把两块板的 `PRESCALE` 设成 121 → **50 Hz**（周期 20 ms，脉宽 0.5~2.5 ms）
- 必须在任何 `PCA9685_Set_Servo_Angle()` 之前调用一次
- 只初始化，**不会动舵机**（不会抖）

### 4.2 `PCA9685_Set_Servo_Angle(channel, angle)`

| 参数 | 范围 | 说明 |
|---|---|---|
| `channel` | 0~17 | 0~8 → 板 1 的 0~8；9~17 → 板 2 的 0~8（内部自动 `ch-9`） |
| `angle` | 0~180 | 单位度；>180 会被夹到 180；注意是 `uint8_t`，**不能传负数** |

内部换算（`pca9685.c`）：`off = 102 + angle × (512-102) / 180`，102 tick ≈ 0.5 ms，512 tick = 20 ms。

调用开销：每路要写 4 个字节寄存器 → 一次调用约 4 次 I2C 事务（100 kHz 下约 1 ms）。
**18 路一轮 ≈ 20 ms**，这决定了步态帧率上限（见下节）。

### 4.3 出问题先看地址

板 1 = `0x40`（写地址 `0x80`，A0~A5 接地）；板 2 = **`0x60`**（写地址 `0xC0`，A0 误焊到 A5）。
只有板 1 的舵机动 → 板 2 的 I2C 没通或地址不对。

## 5. 高层步态函数

### 5.1 `Gait_Init()`

```c
void Gait_Init(void);
```

- 让 6 条腿一次性摆到 `LEG_HOME` 表里的站姿（内部会自动做 IK + 角度换算）
- 无延时、不阻塞；上电时建议先让 18 路都到 90°（`main.c` 已这么做），再调它
- 调用后腿会**动**，第一次上电务必架空
- 它等价于 `Gait_Home()`；运行中想把六条腿重新拉回站姿，直接调 `Gait_Home()` 就行

现 `LEG_HOME` 的站姿：每腿径向 117.2 mm、高 75.2 mm、方位 50°/90°/130°，
对应舵机 **髋 50/90/130、股 16.0、膝 162**（股关节 `DIR_FEMUR = −1`，servo = 90 − ∠1）。

### 5.2 `Gait_TripodStep(stride, lift, phase)` —— 非阻塞单帧

```c
void Gait_TripodStep(float stride, float lift, float phase);
```

| 参数 | 单位 | 建议范围 | 说明 |
|---|---|---|---|
| `stride` | mm | 20~30 | 一个周期的前后摆幅（总行程，单侧 ±stride/2） |
| `lift` | mm | **10~15** | 摆动相抬腿高度；太大膝关节会先撞 ±90° 限位 |
| `phase` | 0.0~1.0 | — | 周期进度；<0 当 0，≥1 当 0.999 |

相位语义：

```text
phase 0.0 ────── 0.5 ────── 1.0
      │ A 组(1,3,5) 摆动 │ B 组(2,4,6) 摆动 │
      │ B 组支撑         │ A 组支撑         │
```

- 一次调用只算一帧，**立即返回**，不会自己延时 → 适合放进定时器中断或主循环
- 调用频率 = 步态速度：50 Hz（每 20 ms 一帧，20 帧/周期 → 一周期 400 ms 走一步）
- 实测包络（stride 30 / lift 10）：髋 44.8~135.2°、股 154.8~170.5°、膝 149.8~171.9°，
  都在软限位内无截断

### 5.3 `Gait_WalkSteps(n, stride, lift)` —— 阻塞版

```c
void Gait_WalkSteps(int n, float stride, float lift);
```

- 走 `n` 步，每周期 20 帧 × `HAL_Delay(10)` = **200 ms/步**，期间 CPU 全被占住
- 只适合调试/演示；正式跑建议改用 5.2 + 定时器（见 6.2）
- 注意 `main.c` 现在是 `while (0)`（死循环不执行），想让它跑要给 `Gait_WalkSteps()` 一个入口

## 6. 能直接抄的例子

### 6.1 最简单的走两步（替换 `main.c` 的 `while (0)`）

```c
while (1) {
    Gait_WalkSteps(2, 25.0f, 10.0f);   /* 走 2 步 */
    HAL_Delay(1000);
    Gait_Init();                        /* 回站姿 */
    HAL_Delay(1000);
}
```

### 6.2 非阻塞步态（推荐，主循环里干别的事也不耽误）

```c
/* main.c 的 while (1) 里 */
static uint32_t last = 0;
static float    phase = 0.0f;
uint32_t now = HAL_GetTick();

if (now - last >= 20) {          /* 50 Hz */
    last = now;
    Gait_TripodStep(25.0f, 10.0f, phase);
    phase += 0.05f;               /* 20 帧 = 1 周期 */
    if (phase >= 1.0f) phase -= 1.0f;
}
```

### 6.3 起身 / 蹲下（改 z）

在 `gait.c` 里加：

```c
void Gait_Stand(float z) {                  /* z = -75.2 站姿，-90 更蹲一点 */
    for (int i = 0; i < LEG_NUM; i++) {
        FootPos p = LEG_HOME[i];
        LegAngles a = inverseKinematics(p.x, p.y, z);
        PCA9685_Set_Servo_Angle(CH_HIP[i],   hip_angle(i,   a.hip));
        PCA9685_Set_Servo_Angle(CH_FEMUR[i], femur_angle(i, a.femur));
        PCA9685_Set_Servo_Angle(CH_TIBIA[i], tibia_angle(i, a.tibia));
    }
}
```

`gait.h` 里加声明，`main.c` 调用 `Gait_Stand(-90.0f);`。
注意：现几何下**抬高身体（z 靠近 0）反而会把 d 压到 124.3 以下**，腿被迫伸直，
所以不要指望 `z = -20` 这种"半蹲"姿态，能用的站立高度大约就是 60~110 mm。

### 6.4 单腿画圆（测试 IK 和标定，最直观）

用 3.2 的 `Gait_SetFoot()` 就够，不需要额外写函数：

```c
/* 放在 main.c 的 USER CODE 2 里，Gait_Init() 之后 */
Gait_Home();
for (int k = 0; k <= 36; k++) {                 /* 一圈 36 帧 */
    float t = (float)k / 36.0f * 6.2831853f;
    Gait_SetFoot(2,                             /* 2 号腿 = 中左腿 */
                 0.0f   + 25.0f * cosf(t),      /* x 在 home 附近 ±25 mm */
                 117.2f,                        /* y 不变 */
                 -75.2f + 25.0f * sinf(t));     /* z 在 home 附近 ±25 mm */
    HAL_Delay(30);
}
Gait_Home();
```

半径取 25 mm 是安全值：再大就会把 `d` 推出 `124.3~167.9` 窗口，被自动投影到边界（看起来
"圆被切掉一块"）。用它肉眼验证"角度方向对不对、中位准不准"非常有效。

### 6.5 原地转向（思路，未实现）

三角步态的摆动相在 `x + [-stride/2, +stride/2]` 之间扫。转向只要让**左侧腿和右侧腿的
stride 符号相反**即可（左腿往前、右腿往后 = 原地右转）。建议不要改 `Gait_TripodStep` 本体，
而是加一层：

```c
Gait_TripodStep(stride_left, lift, phase);    /* 内部按腿号左右分号 */
```

## 8. 常见错误排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 腿瞬间甩到 0° 或 180° | IK 越界返回全 0（旧代码） / DIR 填反 | 现在越界会投影到边界；检查 `DIR_*` |
| 舵机顶住"哒哒"响 | 目标角度超出机械可达（多半是 d 被压到 124.3 以下） | 调小 lift、或把 `z` 调深，必要时收紧 `LEG_MIN/MAX_DEG` |
| 左右不对称 | 中位锚点或 DIR 不对 | 先看 18 路 90° 是否对称，再调 `HIP_MID_DEG` |
| 站姿和手册 §7 不一样 | 现装法是"90° 时腿竖直向上"，不是手册写的中位 | 看 `LEG_IK_NEUTRAL_UP`，确认装配方向 |
| 某条腿完全不动 | 通道表或板 2 地址不对 | 查 `CH_*` 表和 `0x60` |
| 编译报 `M_PI` 未定义 | 用的 newlib 没开 math 宏 | 取消 `leg_ik.c` / `gait.c` 顶部那行注释 |
| 传了负数角度给驱动 | 参数是 `uint8_t` | 角度层已经保证 0~180，别绕过它直接传 |
| 步态一卡一卡 | `HAL_Delay` 阻塞 / I2C 太慢 | 用 6.2 的非阻塞写法，或把 I2C 提到 400 kHz |
