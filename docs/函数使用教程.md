# 函数使用教程

本文讲清楚工程里**每个能调用的函数怎么用**：参数什么单位、返回值什么意思、能传什么值、
用错了会怎样，最后给几个能直接抄的实战例子。

> 配套代码：`Core/Inc/leg_ik.h`、`Core/Src/leg_ik.c`、`Core/Inc/gait.h`、`Core/Src/gait.c`、
> `Core/Inc/pca9685.h`、`Core/Src/pca9685.c`。

---

## 0. 先看全局：三层结构

```text
  你写的动作               几何层                角度层                  驱动层
  ┌──────────┐   ┌────────────────────┐   ┌────────────────────┐   ┌──────────────────────┐
  │ 足端坐标  │ → │ inverseKinematics  │ → │ hip/femur/tibia_   │ → │ PCA9685_Set_Servo_   │ → PWM
  │ (x,y,z)mm│   │  → LegAngles(弧度) │   │ angle → 0~180°     │   │ Angle(ch 0~17, 0~180)│
  └──────────┘   └────────────────────┘   └────────────────────┘   └──────────────────────┘
      gait.c           leg_ik.c                 gait.c                    pca9685.c
```

| 层 | 文件 | 函数 | 输入单位 | 输出单位 |
|---|---|---|---|---|
| 几何层 | `Core/Src/leg_ik.c` | `inverseKinematics()` | mm | 弧度 |
| 角度层 | `Core/Src/gait.c` | `hip_angle()` / `femur_angle()` / `tibia_angle()`（内部 static） | 弧度 | 0~180 度 |
| 驱动层 | `Core/Src/pca9685.c` | `PCA9685_Set_Servo_Angle()` | 度 | PWM tick |
| 高层 | `Core/Src/gait.c` | `Gait_Init()` / `Gait_TripodStep()` / `Gait_WalkSteps()` | mm | — |

**关键点**：几何层只管"数学角"，绝不掺舵机安装方向；所有"机械中位 ↔ 舵机 90°"的换算
**只**在角度层做。这样换舵机/换装法时只改一张表，不动数学。

## 1. 全局约定（看错这里 = 90% 的 bug）

### 1.1 坐标系

相对**该腿的髋关节旋转中心**：

| 轴 | 正方向 | 例子 |
|---|---|---|
| `x` | 向前 | 足端比髋靠前 50 mm → `x = +50` |
| `y` | 向左 | 左腿足端在外侧 → `y = +60`；右腿 → `y = -60` |
| `z` | 向上 | 足端在身体下方 → `z = -110` |

单位 **mm**。一次调用只算**一条腿**，六条腿各调一次。

### 1.2 腿号与通道号

| 腿号 | 位置 | 髋/股/膝 逻辑通道 |
|---|---|---|
| 1 | 前左 | 0 / 1 / 2 |
| 2 | 中左 | 3 / 4 / 5 |
| 3 | 后左 | 6 / 7 / 8 |
| 4 | 前右 | 9 / 10 / 11 |
| 5 | 中右 | 12 / 13 / 14 |
| 6 | 后右 | 15 / 16 / 17 |

通道 0~8 在板 1（0x40），9~17 在板 2（0x60）。**C 数组下标是 0~5，对应腿 1~6。**

### 1.3 角度约定

- 舵机角度统一 **0~180°**，90° = 机械中位（手册 §7 的装配姿态）
- 软限位 **15~165°**，超出会被 `joint_angle()` 夹住（MG90S 别顶死）
- IK 输出的 `tibia` 是 `π − 膝内角 K`，不是膝内角本身：
  `tibia = 0` 伸直、`tibia = π/2` 膝内角 90°（= 舵机中位）、`tibia = π` 完全折叠

## 2. 几何层：`inverseKinematics()`

```c
LegAngles inverseKinematics(float x, float y, float z);
```

### 2.1 参数

| 参数 | 类型 | 单位 | 说明 |
|---|---|---|---|
| `x` | float | mm | 足端相对髋中心的前后位置，正=前 |
| `y` | float | mm | 左右位置，左腿为正、右腿为负 |
| `z` | float | mm | 上下位置，足端在下 → 负值 |

### 2.2 返回值 `LegAngles`

| 字段 | 单位 | 含义 |
|---|---|---|
| `.hip` | 弧度 | 水平旋转角。`0` = 腿朝正前，`+π/2` = 朝正左 |
| `.femur` | 弧度 | 大腿抬落角。`0` = 大腿水平，`+` = 抬起 |
| `.tibia` | 弧度 | `π − 膝内角 K`。`π/2` = 膝内角 90° |

### 2.3 例子：中左腿回到 home

```c
LegAngles a = inverseKinematics(0.0f, 60.0f, -110.0f);
/* 结果（角度换算后）：
 *   hip   = 90.0°   （朝正左）
 *   femur ≈ -1.8°   （大腿几乎水平）
 *   tibia ≈ 98.7°   （膝内角约 81°，略屈）
 * 对应舵机（见下节）：髋 90.0 / 股 88.2 / 膝 98.7
 */
#define RAD2DEG(r)  ((r) * 57.29578f)
```

### 2.4 越界会怎样（重要）

腿的工作空间（肩轴到足端的直线距离 D）：

```text
最近 D = |L2 - L3| = 52.1 mm      （膝盖完全折叠）
最远 D =  L2 + L3  = 167.9 mm     （腿完全伸直）
```

超出范围时**不会**像旧代码那样返回全 0（那会让整条腿瞬间甩到 0°），而是把目标点
**沿"髋→足端"的视线缩放到最近的可达边界**（`leg_ik.c:59-76`），所以：

- 输出的角度连续，不会跳变；
- 足端实际到不了你给的点，但方向是对的；
- 想确认有没有被截断，用 `python tools/ik_check.py` 算，或在调试时看 `D` 是否 > 167.9。

### 2.5 三个常见错误

| 写法 | 后果 | 正确做法 |
|---|---|---|
| `inverseKinematics(0, 0, -110)` | 足端压在肩轴上，`D < 1mm` 走病态保护，角度乱 | `y` 必须给腿的横向偏移 |
| `inverseKinematics(50, 60, 110)` | z 传正数 = 足端在身体上方，相当于腿朝天 | 足端在下方时 `z` 为负 |
| 传 `(50, 60, -110)` 的毫米值当米 | 角度会瞬间打满限幅 | 只认 mm |

## 3. 角度层：`hip_angle()` / `femur_angle()` / `tibia_angle()`

这三个是 `gait.c` 里的 **static 内部函数**，签名：

```c
static uint8_t hip_angle  (int leg, float rad);   /* leg = 0~5，对应腿 1~6 */
static uint8_t femur_angle(int leg, float rad);
static uint8_t tibia_angle(int leg, float rad);
```

它们干的事（`gait.c:103-111` 的 `joint_angle()`）：

```text
servo = 90 + DIR[leg] × (ikDeg - MID[leg]) + TRIM[ch]
然后限幅到 15 ~ 165，四舍五入成 uint8_t
```

| 关节 | `MID`（舵机 90° 时该关节的 IK 角） | `DIR` | 依据 |
|---|---|---|---|
| 髋 | 左腿 `+90°`、右腿 `-90°` | 左 `+1`、右 `-1` | 舵机 90° 时摇臂指向该腿正外侧 |
| 股 | `0°`（大腿水平） | 全 `+1` | 装配中位就是水平 |
| 膝 | `90°`（膝内角 90°） | 全 `+1` | 装配中位小腿垂直 |

为什么不能像旧代码那样"三个关节一律 +90°"：新腿长 L3=110 ≫ L2=57.9，旧映射下舵机
90° 对应的是膝内角 180°（腿伸直），home 姿态会被硬顶到 165° 限幅。详见《代码修改指导手册》M2/M4。

### 3.1 想改哪里就改哪里

| 现象 | 改这个（`Core/Src/gait.c`） |
|---|---|
| 某条腿某个关节**转反**了 | `DIR_HIP[6]` / `DIR_FEMUR[6]` / `DIR_TIBIA[6]` 对应格改成 `-1` |
| 某一路**固定偏几度** | `SERVO_TRIM[18]`，下标 = 腿号(0~5)×3 + 关节(0髋/1股/2膝) |
| 六条腿髋**整体**偏同一角度 | `HIP_MID_DEG[6]` |
| 想收紧软限位 | `SERVO_MIN_DEG` / `SERVO_MAX_DEG` |

例：1 号腿髋偏 -4° → `SERVO_TRIM[0] = -4`；4 号腿膝转反 → `DIR_TIBIA[3] = -1`。

### 3.2 想在 `main.c` 里直接控制单条腿？

这三个是 static，`main.c` 调不到。做法是在 `gait.c` 里加一个公开包装（5 行）：

```c
/* 加到 Core/Src/gait.c 末尾 */
void Gait_SetFoot(uint8_t leg, float x, float y, float z) {
    if (leg >= LEG_NUM) return;
    LegAngles a = inverseKinematics(x, y, z);
    PCA9685_Set_Servo_Angle(CH_HIP[leg],   hip_angle(leg,   a.hip));
    PCA9685_Set_Servo_Angle(CH_FEMUR[leg], femur_angle(leg, a.femur));
    PCA9685_Set_Servo_Angle(CH_TIBIA[leg], tibia_angle(leg, a.tibia));
}
```

```c
/* 加到 Core/Inc/gait.h 的 (#ifdef __cplusplus 之前) */
void Gait_SetFoot(uint8_t leg, float x, float y, float z);
```

之后就能在 `main.c` 里 `Gait_SetFoot(0, 50, 60, -110);` 精确摆一条腿。

## 4. 驱动层：`pca9685.c`

```c
void PCA9685_Init(I2C_HandleTypeDef *hi2c1, I2C_HandleTypeDef *hi2c2);
void PCA9685_Set_Servo_Angle(uint8_t channel, uint8_t angle);
```

### 4.1 `PCA9685_Init()`

- 传两条 I2C 总线（板 1 用 `hi2c1`，板 2 用 `hi2c2`，**地址不同**）
- 内部把两块板的 `PRESCALE` 设成 121 → **50 Hz**（周期 20 ms，脉宽 0.5~2.5 ms）
- 必须在任何 `PCA9685_Set_Servo_Angle()` 之前调用一次
- 只初始化，**不会动舵机**（不会抖）

### 4.2 `PCA9685_Set_Servo_Angle(channel, angle)`

| 参数 | 范围 | 说明 |
|---|---|---|
| `channel` | 0~17 | 0~8 → 板 1 的 0~8；9~17 → 板 2 的 0~8（内部自动 `ch-9`） |
| `angle` | 0~180 | 单位度；>180 会被夹到 180；注意是 `uint8_t`，**不能传负数** |

内部换算（`pca9685.c:46`）：`off = 102 + angle × (512-102) / 180`，102 tick ≈ 0.5 ms，512 tick = 20 ms。

调用开销：每路要写 4 个字节寄存器 → 一次调用约 4 次 I2C 事务（100 kHz 下约 1 ms）。
**18 路一轮 ≈ 20 ms**，这决定了步态帧率上限（见下节）。

### 4.3 出问题先看地址

板 1 = `0x40`（写地址 `0x80`，A0~A5 接地）；板 2 = **`0x60`**（写地址 `0xC0`，A0 误焊到 A5）。
只有板 1 的舵机动 → 板 2 的 I2C 没通或地址不对。

## 5. 高层步态函数

### 5.1 `Gait_Init()`

```c
void Gait_Init(void);
```

- 让 6 条腿一次性摆到 `LEG_HOME` 表里的站姿（内部会自动做 IK + 角度换算）
- 无延时、不阻塞；上电时建议先让 18 路都到 90°（`main.c:97-110` 已这么做），再调它
- 调用后腿会**动**，第一次上电务必架空

### 5.2 `Gait_TripodStep(stride, lift, phase)` —— 非阻塞单帧

```c
void Gait_TripodStep(float stride, float lift, float phase);
```

| 参数 | 单位 | 建议范围 | 说明 |
|---|---|---|---|
| `stride` | mm | 20~40 | 一个周期的前后摆幅（总行程，单侧 ±stride/2） |
| `lift` | mm | 10~25 | 摆动相抬腿高度 |
| `phase` | 0.0~1.0 | — | 周期进度；<0 当 0，≥1 当 0.999 |

相位语义：

```text
phase 0.0 ────── 0.5 ────── 1.0
      │ A 组(1,3,5) 摆动 │ B 组(2,4,6) 摆动 │
      │ B 组支撑         │ A 组支撑         │
```

- 一次调用只算一帧，**立即返回**，不会自己延时 → 适合放进定时器中断或主循环
- 调用频率 = 步态速度：50 Hz（每 20 ms 一帧，20 帧/周期 → 一周期 400 ms 走一步）
- 实测包络（stride 30 / lift 20）：髋 42.7~137.3°、股 88.2~110.2°、膝 85.4~117.8°，余量充足

### 5.3 `Gait_WalkSteps(n, stride, lift)` —— 阻塞版

```c
void Gait_WalkSteps(int n, float stride, float lift);
```

- 走 `n` 步，每周期 20 帧 × `HAL_Delay(10)` = **200 ms/步**，期间 CPU 全被占住
- 只适合调试/演示；正式跑建议改用 5.2 + 定时器（见 6.2）
- 注意 `main.c:116` 现在是 `while (0)`（死循环不执行），想让它跑要给 `Gait_WalkSteps()` 一个入口

## 6. 能直接抄的例子

### 6.1 最简单的走两步（替换 `main.c` 的 `while (0)`）

```c
while (1) {
    Gait_WalkSteps(2, 30.0f, 20.0f);   /* 走 2 步 */
    HAL_Delay(1000);
    Gait_Init();                        /* 回站姿 */
    HAL_Delay(1000);
}
```

### 6.2 非阻塞步态（推荐，主循环里干别的事也不耽误）

```c
/* main.c 的 while (1) 里 */
static uint32_t last = 0;
static float    phase = 0.0f;
uint32_t now = HAL_GetTick();

if (now - last >= 20) {          /* 50 Hz */
    last = now;
    Gait_TripodStep(30.0f, 20.0f, phase);
    phase += 0.05f;               /* 20 帧 = 1 周期 */
    if (phase >= 1.0f) phase -= 1.0f;
}
```

### 6.3 起身 / 蹲下（改 z）

在 `gait.c` 里加：

```c
void Gait_Stand(float z) {                  /* z = -110 站姿，-70 蹲下 */
    for (int i = 0; i < LEG_NUM; i++) {
        FootPos p = LEG_HOME[i];
        LegAngles a = inverseKinematics(p.x, p.y, z);
        PCA9685_Set_Servo_Angle(CH_HIP[i],   hip_angle(i,   a.hip));
        PCA9685_Set_Servo_Angle(CH_FEMUR[i], femur_angle(i, a.femur));
        PCA9685_Set_Servo_Angle(CH_TIBIA[i], tibia_angle(i, a.tibia));
    }
}
```

`gait.h` 里加声明，`main.c` 调用 `Gait_Stand(-90.0f);`。注意 z 越靠近 0 腿越伸直，
超过 `D = 167.9` 会被自动截断（角度层照常输出，不会崩）。

### 6.4 单腿画圆（测试 IK 和标定，最直观）

```c
/* 加到 gait.c 末尾，gait.h 加 void Gait_LegCircle(uint8_t leg, float r); */
void Gait_LegCircle(uint8_t leg, float r) {
    for (int k = 0; k <= 36; k++) {                 /* 一圈 36 帧 */
        float t = (float)k / 36.0f * 6.2831853f;
        FootPos h = LEG_HOME[leg];
        float x = h.x + r * cosf(t);
        float z = h.z + r * sinf(t);
        LegAngles a = inverseKinematics(x, h.y, z);
        PCA9685_Set_Servo_Angle(CH_HIP[leg],   hip_angle(leg,   a.hip));
        PCA9685_Set_Servo_Angle(CH_FEMUR[leg], femur_angle(leg, a.femur));
        PCA9685_Set_Servo_Angle(CH_TIBIA[leg], tibia_angle(leg, a.tibia));
        HAL_Delay(30);
    }
}
```

`Gait_LegCircle(1, 25.0f);` 会让 2 号腿原地画半径 25 mm 的圆——用来肉眼验证
"角度方向对不对、中位准不准"非常有效。

### 6.5 原地转向（思路，未实现）

三角步态的摆动相在 `x + [-stride/2, +stride/2]` 之间扫。转向只要让**左侧腿和右侧腿的
stride 符号相反**即可（左腿往前、右腿往后 = 原地右转）。建议不要改 `Gait_TripodStep` 本体，
而是加一层：

```c
Gait_TripodStep(stride_left, lift, phase);    /* 内部按腿号左右分号 */
```

（留给你自己实现；改之前先跑 `ik_check.py` 看角度会不会撞限幅。）

## 8. 常见错误排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 腿瞬间甩到 0° 或 180° | IK 越界返回全 0（旧代码） / DIR 填反 | 现在越界会投影到边界；检查 `DIR_*` |
| 舵机顶住"哒哒"响 | 目标角度超出机械可达 | 收紧 `SERVO_MIN/MAX`，或调小 stride/lift |
| 左右不对称 | 中位锚点或 DIR 不对 | 先看 18 路 90° 是否对称，再调 `HIP_MID_DEG` |
| 某条腿完全不动 | 通道表或板 2 地址不对 | 查 `CH_*` 表和 `0x60` |
| 编译报 `M_PI` 未定义 | 用的 newlib 没开 math 宏 | 取消 `leg_ik.c` / `gait.c` 顶部那行注释 |
| 传了负数角度给驱动 | 参数是 `uint8_t` | 角度层已经保证 0~180，别绕过它直接传 |
| 步态一卡一卡 | `HAL_Delay` 阻塞 / I2C 太慢 | 用 6.2 的非阻塞写法，或把 I2C 提到 400 kHz |

## 9. 不用上机就能验证

`tools/ik_check.py`（纯 Python 标准库，镜像了固件的全部数学）：

```bat
python tools\ik_check.py                     :: 默认参数
python tools\ik_check.py --stride 25 --lift 15
```

它会打印：工作空间上下界、home 姿态下 6 条腿的 D 和 18 路舵机角、步态包络是否撞限幅。
最后一行为 `全部通过 ✅` 或问题数量。**改任何参数后先跑它，比烧板子快 100 倍。**
