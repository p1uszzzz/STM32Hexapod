# 驱动下载清单（新电脑第一次用必须装一次）

在新电脑上，**工具是免安装的（U 盘里就有），只有 USB 驱动必须装一次** —— 这是唯一需要管理员权限的步骤。
把下载好的安装包直接丢进本文件夹，然后运行 `tools\lab\prepare_usb.bat`，它会把整个 `drivers\` 拷到 U 盘上。

> 装一次就永久有效，同一台实验室电脑以后都不用再装。

## 按你手上的调试器，只需要装对应的那一个

| 手上的硬件 | 需要下载的安装包 | 官方地址 | 说明 |
|---|---|---|---|
| **ST-LINK V2 / V2.1**（推荐） | `STSW-LINK009`（ST-Link USB driver） | https://www.st.com/en/development-tools/stsw-link009.html | 约 1 MB，解压后右键 `stlink_winusb_install.bat` → 以管理员身份运行 |
| ST-LINK 想连图形界面一起用 | `STM32CubeProgrammer`（安装时自带 ST-Link + DFU 驱动） | https://www.st.com/en/development-tools/stm32cubeprog.html | 约 300 MB，安装勾选 "ST-LINK driver"；装完 U 盘里的 CLI 也能用 |
| **CH340 / CH341 USB-TTL**（串口烧录） | `CH341SER.EXE` | https://www.wch.cn/downloads/CH341SER_EXE.html | 约 300 KB，双击 → 安装 |
| **CP2102 USB-TTL** | `CP210x Universal Windows Driver` | https://www.silabs.com/developer-tools/usb-to-usb-bridge-vcp-drivers | 解压后右键 `silabser.inf` → 安装 |
| **USB DFU**（BOOT0=1） | STM32CubeProgrammer 已含 DFU 驱动 | 同上 | Win10/11 有时能自动识别 |

> ST 官网下载需要登录 ST 账号（免费注册），国内访问慢；建议**在家提前下好**再拷 U 盘。
> 如果只买得起一根 USB-TTL，那就下 CH340 驱动，走串口烧录。

## 没有管理员权限怎么办

1. 找实验室管理员/助教帮忙装一次驱动（装完就不用管了）；
2. 或者用一台已经装过 STM32 / Keil / CubeProgrammer 的电脑；
3. 最稳：**带自己的笔记本**，U 盘环境插上就能用（你自己电脑的驱动早就装好了）。

## 装完怎么确认

插上调试器，运行：

```bat
tools\lab\check_devices.bat
```

- 第 1 节列出 `ST-Link` / `CH340 (COMx)` 且状态 `OK`
- 第 3 节 `STM32_Programmer_CLI -l` 能列出 ST-LINK 的序列号

两样都满足，就可以直接 `flash.bat` 了。
